# eeu — Easy Editor с поддержкой UTF-8

[English version](README.md)

`eeu` — самостоятельная версия Easy Editor (`ee`) на основе исходников,
поставляемых с FreeBSD 15.1. Сохранён простой интерфейс оригинального редактора
с меню и подсказками; добавлены обработка UTF-8, корректное перемещение курсора,
редактирование, поиск и русский каталог сообщений.

Штатные `/usr/bin/ee` и `/usr/bin/ree` не заменяются. Ограниченный режим
устанавливается отдельно под именем `reeu`.

## Возможности

- Ввод и отображение UTF-8 через широкосимвольную библиотеку `ncursesw`.
- Перемещение курсора, Backspace, Delete и редактирование строк ввода работают
  с кодовыми точками UTF-8, а не с отдельными байтами.
- Экранная ширина учитывается через `wcwidth()`, включая широкие CJK-символы
  и комбинируемые знаки.
- Поиск без учёта регистра использует Unicode-преобразование регистра активной
  локали.
- Содержимое файлов хранится в исходных байтах: при открытии и сохранении нет
  автоматической перекодировки или нормализации. Некорректные UTF-8-байты
  сохраняются.
- Русифицированы меню, справка, подсказки, диалоги, строка состояния и сообщения
  редактора через стандартный механизм `catgets()`.
- Команды редактора и ключевые слова конфигурации остаются английскими.
  Существующие файлы `.init.ee` совместимы.
- `reeu` запускает ограниченный режим без файловых операций и shell-команд,
  аналогично штатному `ree`.

## Границы поддержки Unicode

Курсор и удаление работают по кодовым точкам Unicode, а не по расширенным
графемным кластерам. Буква с комбинируемыми знаками или составная emoji-последо-
вательность может потребовать нескольких перемещений или нажатий Delete.
Отображение сложных emoji также зависит от терминала и его таблиц ширины.
Поэтому редактор пока не заявляет полноценную обработку графемных кластеров.

Повреждённые UTF-8-последовательности сохраняются в исходном виде; при
отображении вместо некорректных байтов по возможности используется знак замены.

## Требования

На FreeBSD сборка использует системные широкосимвольные библиотеки curses и
terminfo, а также `gencat`. Для редактирования UTF-8 нужна UTF-8-локаль. Для
русского интерфейса нужна локаль `ru_RU.UTF-8` и установленный каталог сообщений.

Основной файл сборки — BSD `Makefile`. `GNUmakefile` предназначен для окружений
с GNU make, где установлены заголовки и библиотека разработки `ncursesw`.

## Сборка и установка на FreeBSD

Из каталога проекта:

```sh
make clean
make
make test
sudo make install
```

По умолчанию используется префикс `/usr/local`. Для установки с отдельным
префиксом, например `/opt/eeu`:

```sh
make PREFIX=/opt/eeu NLS_LOCALE=ru_RU.UTF-8 UTF8_LOCALE=ru_RU.UTF-8
make test PREFIX=/opt/eeu NLS_LOCALE=ru_RU.UTF-8 UTF8_LOCALE=ru_RU.UTF-8
make install PREFIX=/opt/eeu NLS_LOCALE=ru_RU.UTF-8 UTF8_LOCALE=ru_RU.UTF-8
```

При `PREFIX=/opt/eeu` исполняемые файлы устанавливаются в
`/opt/eeu/bin/`, а русский каталог сообщений — в:

```text
/opt/eeu/share/nls/ru_RU.UTF-8/eeu
```

Имя каталога сообщений намеренно изменено с `ee` на `eeu`. В FreeBSD у
установленного файла каталога нет суффикса `.cat`.

## Русский интерфейс в tcsh

Добавь в `~/.tcshrc`:

```tcsh
setenv PATH "/opt/eeu/bin:${PATH}"
setenv NLSPATH "/opt/eeu/share/nls/%L/%N"
setenv LANG ru_RU.UTF-8
setenv LC_CTYPE ru_RU.UTF-8
setenv LC_MESSAGES ru_RU.UTF-8
```

Если задана `LC_ALL`, она имеет приоритет над отдельными переменными локали.
Оставь её незаданной либо укажи подходящую UTF-8-локаль. Затем перечитай
настройки и обнови таблицу команд:

```tcsh
source ~/.tcshrc
rehash
```

Запуск:

```tcsh
eeu filename.txt
```

Чтобы использовать английский интерфейс, выбери английскую локаль для
`LC_MESSAGES`. Если русский каталог не найден, редактор использует встроенные
английские сообщения.

## Тесты

`make test` проверяет UTF-8-модуль и открывает каталог сообщений по базовому
имени `eeu` через `NLSPATH` — тем же способом, которым его открывает редактор.
Проверяются валидность UTF-8, границы кодовых точек, экранная ширина некоторых
символов, выбранные русские сообщения, а также сохранение английских команд и
клавиш подтверждения.

Автоматические тесты не заменяют интерактивную проверку в настоящем терминале
FreeBSD. После сборки проверь ввод, меню, изменение размера окна, поиск,
редактирование и сохранение файлов в используемом терминале.
